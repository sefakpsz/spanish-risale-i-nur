# Reader design decisions

- Preserve the `﷽` Bismillah glyph wherever Bismillah appears in any book. Keep its dark, prominent styling, source position, tap behavior, and Spanish translation bubble.
- If Lemalar is restored later, preserve the exact PDF appearance of the decorative “Birinci Lem’a” heading. The inactive local fixture retains `assets/BirinciLema-local.png` as the approved rendering because the embedded font displayed as question marks on iOS. Keep its source position and accessibility label.
- If a later request seems to change either decision incidentally or ambiguously, ask the owner to confirm that specific change before making it. An explicit, informed request to change one of these decisions supersedes this instruction.
- The inactive title image and Turkish fixture are local development assets with unverified distribution rights. Keep them off the public repository and release builds.
- The Spanish *Tratados Sobre Ramadán, Frugalidad y Agradecimiento* PDF also states that reproduction requires the editor's prior written permission. Keep its extracted pages and heading art local until that permission is documented. Its text layer omits Arabic artwork; visually review each page before claiming a complete transcription.
- Preserve PDF front matter, including imprint/copyright and title pages, with source reading order and recognizable typography. Page 2 of the local Spanish book uses larger, adjustable text; page 3 uses zoomable artwork with accessible text. Apply this choice to future imports when exact artwork would make text too small or disable size controls.
- Omit blank source pages and empty spacer areas from extracted readers. Number visible reader pages consecutively from 1, and keep original PDF page numbers separately as metadata. Keep the reader header free of the `+` bookmark button; bookmarks belong in the bottom controls.
- Never build a distributable release from the local development branch. Static imports can enter a bundle even when hidden behind `__DEV__`; use the clean public `main` branch until publication permissions and a release content audit are complete.
- Show the language toggle only in local development (`__DEV__`). Hide the control in TestFlight and store builds. This visibility rule does not itself remove English translations or change system-language detection; complete the Spanish-only interface audit before public release.
